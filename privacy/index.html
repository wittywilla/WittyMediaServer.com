Privacy

Privacy

Two parts: this website, and the software you install. Neither tracks you.

This website

No cookies, trackers or analytics

wittymediaserver.com is a folder of plain files. There’s no database, no sign-in and nothing to type in.

Nothing follows you

No cookies, no trackers, no analytics and no advertising. No fonts, scripts or pictures come from anywhere else.

Your theme stays with you

The theme you pick is kept in your own browser, and never sent anywhere. Match my device forgets it.

Checking for newer releases

The front page, News and Modules ask GitHub whether anything came out since the site was made. GitHub then sees your address and browser, as with any visit, and its own privacy statement applies.

Downloads come from GitHub

Download buttons go straight to the project’s releases on GitHub. Links to the guides and source code go there too.

What your browser keeps

  • wms-site-theme: the theme you chose, until you choose Match my device. Nothing is kept if you never pick one.
  • GitHub’s answers about new releases, for ten minutes, so moving between pages doesn’t ask again. They go when you close the tab.

Without JavaScript

Every page reads without it. Then nothing is kept in your browser and GitHub is never asked. A strict security policy lets pages reach only this site and, for those checks, GitHub.

Like any website, the host that serves these files may keep the usual server logs of visits.

The software

Your server is yours

No telemetry, no accounts with anyone and no cloud. Here’s exactly what leaves a server, and when.

In the server’s own words, from Settings → Legal → Privacy:

No telemetry. No usage data, error reports or analytics go to the project or to anyone else, and there’s no account with the project. App errors, if an administrator turns that logging on, go only to this server.

Your files, watch history, passwords and logs aren’t sent anywhere. What leaves this server is what’s listed here, each with what controls it. Names sent to look something up come from your file and folder names, so choose them with that in mind. Each service also sees the internet address of whichever computer contacts it, usually this server’s, and its own privacy policy applies.

On by default: the update checks, TVmaze and Wikidata, the libretro database and thumbnails for games, MusicBrainz and the Cover Art Archive for audio CD images, Radio Browser, plus AniList once there’s an Anime library, and answering apps that look for servers on your home network. Everything else is off until someone turns it on or uses it.

Whoever runs this server can see what its accounts do on it, including what’s played and from which address, and its logs keep warnings such as repeated wrong passwords, with the address they came from, for 14 days. If you use a server someone else runs, ask them what they keep.

GitHub (updates)

Gets
The version this server runs and the name of the project. When installing, also which system the download is for.
When
On by default: twice a day for server and module updates. Downloads only when an administrator installs one, or with automatic module install turned on.
Controlled in
Settings, About (Updates) and Settings, Modules

TVmaze

Gets
Show names, taken from your folder and file names.
When
On by default, at each scan and refresh, until a TheTVDB key is added. Only for TV libraries.
Controlled in
Settings, Metadata agents

Wikidata and Wikipedia

Gets
Movie and game titles, taken from your folder and file names.
When
On by default, at each scan and refresh. For movies, until a TMDB key is added.
Controlled in
Settings, Metadata agents

libretro database

Gets
Nothing about your games: a list for each console you have is downloaded, and matched on this server.

On by default for Games libraries: each console’s list once, then checked monthly.

libretro thumbnails

Gets
The names of your games, as the database lists them.
When

Your own network

Gets
This server’s name, a random ID, its version, port and address, to devices on your home network that ask. If turned on, port-forwarding requests go to your router. Searching for tuners contacts tuners on your network.
When
Answering devices is on by default. It never leaves your home network.
Controlled in
Settings, Profiles (Let apps find this server); Settings, Remote Access

The apps

And the apps

WittyMediaClient

No telemetry. Error reports go to the server you’re connected to, and its owner can turn them off. On the internet it insists on https://.

WittyMediaPlayer

Plays discs and files on your own computer, with no server and no account.

WittyReader

Read and annotate books, PDFs and comics on your own device, with no server and nothing uploaded.

From the README, Updating, Logging and Apps and devices. Want to keep your server off the internet altogether? It is, until you turn on Remote Access: see Remote access.
