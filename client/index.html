WittyMediaClient

Apps for TV boxes, phones, tablets and desktops that connect to your WittyMediaServer, for the devices where a browser isn’t the right fit.

0.6.0Released 23 November 2026GPL-3.0-or-later
DownloadGitHub

Early days. Optional. The server’s whole interface already runs in any web browser. Android has been run on emulators only, the Mac app has never been launched, and the iPhone, iPad and Apple TV apps have run in Apple’s simulators only, never on a device, and aren’t released yet. A web browser is the way to reach everything today.

What it does

A dedicated app, where it helps

Finds your server

Finds it on your network, or takes its address, and signs in with a code or a password. It checks the server’s identity first.

Plays films and shows

With resume, on the native apps. The desktop app is a window around the server’s own pages.

Remote, keyboard or touch

Built for the sofa as much as the desk: on a TV, the arrows and OK reach everything. Real TV remotes haven’t been tried yet.

Games on your own PC

Through the server’s page where it can, with the separately installed Moonlight app as the fallback. Not yet tried against a real PC from these apps.

Your server’s pages

With server 0.8.0-alpha, the apps draw Home, libraries, titles and search from the server’s page descriptions, modules’ own pages included, so pages arranged on the server look the same in every app. Settings stays the app’s own. Against an older server they keep their own pages.

From anywhere

With a server that has peer-to-peer connections on, the desktop, Apple and Android apps pair themselves at home and reach the server from anywhere afterwards, still signed in, with nothing set up on the router. <a href=”/remote/”>How it works</a>.

Sign in with your phone

A TV shows a QR code and a PIN that changes every 30 seconds; approve it from a signed-in phone, with no password typed on the TV.

Your servers, tidy

Saved servers come first. A server is one entry however its address changes, and old ones can be removed, with Undo, or all that haven’t been reached for a while. Nothing is removed by itself.

Layouts

The desktop and Android apps draw the server’s layouts: a sidebar or rail, tabs across the top, a phone’s tab bar, or a TV’s top or side menu, chosen for each device.

The Android and Apple apps say plainly when something can’t play there yet. Music, podcasts, live TV, books, photos, disc menus and games on the server need the desktop app or a browser for now. There’s no telemetry: error reports go to the server you’re connected to, and its owner can turn them off.
