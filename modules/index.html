Modules

Modules add what your server can do, such as DVD menus, streamed games or live TV. Most are projects of their own, signed, and added from Settings → Modules while the server keeps running.

How they work

Safe to add, easy to take away

Signed

Each version’s files are listed with their checksums, and the list is signed. The server checks both before anything runs.

Limited

A module lists what it asks for, such as the network or a folder of its own. The server keeps its own list of which modules may have each, and starts their programs in a sandbox where the system has one.

Yours to remove

Turn a module off or remove it whenever no library or other module needs it. Your media, watch history and settings stay as they are.

Modules work with server 0.6.0-alpha and later. Each module page says which server versions it fits.

Alpha software: it changes quickly and can fail or lose data. Keep backups, including your data folder, before you upgrade. No media comes with WittyMediaServer. Copy-protected discs, encrypted broadcasts and encrypted game files are refused with a plain message. Nothing here unlocks them.
