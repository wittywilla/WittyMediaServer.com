After installing

From download to your first film

  1. Open it. On Windows and a Mac, open WittyMediaServer and your browser opens its setup page. On Linux, FreeBSD and Docker it runs in the background: go to http://<this computer>:9797.
  2. Make your account. The first account looks after libraries, people and settings. From another device, setup asks for a code that the server shows when it starts.
  3. Choose what you want. Films, TV and music work straight away. Tick discs, games, photos or books, and their modules download, which needs an internet connection.
  4. Add a folder. Point a library at your films or shows, and it finds what’s there.
  5. Watch anywhere. Open the server’s address, such as http://192.168.1.20:9797, on any screen in your home. Setup’s last page shows it.
Getting started guideEvery way to install

This is an alpha. it changes quickly and can fail or lose data. Keep backups, including your data folder, before you upgrade. Linux gets the most testing. The Windows installer has been tested under Wine, not on real Windows. The FreeBSD package has run in virtual machines, not on real hardware. The Mac installer has never been run.

The downloads aren’t code-signed yet, so Windows and macOS warn about them. On Windows, choose More info, then Run anyway. On a Mac, right-click the server’s installer, choose Open, and Open again. For the apps, use Open Anyway in System Settings → Privacy & Security.

No media comes with WittyMediaServer. It’s licensed under Apache-2.0 and comes “as is”, with no warranty. Add only media you have the right to use. The legal notes have the rest. New to all this? Start here.
