# WittyMediaServer
Self-hosted software that stores and streams your films, shows, discs, music, books and games from your own hardware. It plays DVDs and Blu-rays with their real menus, in any browser on your home network.
Install it once on a machine you own. Every screen in your home reaches it through a web browser — no app required.

## What it does
Holds your library of films, shows, discs, music, books and games on hardware you own, and streams them to any browser on your network.
Plays DVDs and Blu-rays with their real menus — the same navigation a standalone player would show — straight in the browser.
Runs a signed module catalog, so you can add features from separate repositories without forking the server.
Serves a web interface every device can reach, so a dedicated app is optional, not required.
The server is the part you install. WittyMediaClient is the optional companion for devices where a browser isn’t the right fit.
## Where it runs
Windows, macOS, Linux, FreeBSD — install it on a machine you own and reach it from any browser on your network.
Docker — run it as a container alongside your other self-hosted services.
Modules — extend it with features from separate, signed repositories.
