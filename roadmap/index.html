Roadmap

Where it’s going

What’s being finished now, what’s still to build, and what hasn’t met the real world yet. Taken from the project’s own roadmap each time this site is made.

0.6.2-alphaThe newest releaseMade 5 November 2026
The roadmap on GitHubSuggest a feature

A long alpha, on purpose. WittyMediaServer stays in alpha until every planned feature is at least partly built. Only then does it move to beta. Nothing here has a date, and plans can change.

  1. Still to build · 0 items

    Now: 0.7.0-alpha

    0.6.0-alpha was published on 2026-11-02, then 0.6.1-alpha and 0.6.2-alpha as urgent fixes. 0.7.0-alpha started on 2026-11-04, small but robust: its work is in the 0.7.0-alpha milestone, one issue each, with the release checklist in #84. Features wait as ideas in Discussions until work on them starts.

    The plans and designs for what comes after, each with what’s done, in progress or planned, are in Plans.

  2. Still to build · 26 items

    Still to build

    The server and its libraries 7

    • Watch together: a shared, synchronised player across profiles and devices
      Not startedBest built with real networks to test across
    • WittyRelay: a hosted way in from away, planned as a free service
      Not builtIt’s shown greyed out in Settings → Remote Access
    • Photos: batch rotate and edit
      Not started
    • Local AI: a plan document, with image recognition for photos as the first use
      Not writtenThe marked placeholders are in: People & places in photos, and GET /api/photos/ai says it isn’t available
    • Recordings in a series’ own folder
      Not startedRecordings go to one folder, or a chosen library’s
    • A minimum hardware document: realistic specifications for the server and for disc playback
      Not written: #113
    • Sandbox on FreeBSD and macOS: a module’s helper runs with none there, only a small environment and a soft memory limit
      Not built

    Discs, tuners and games 5

    • Blu-ray: mixing in secondary audio and picture-in-picture, and MVC 3D decoding
      Not builtFFmpeg has no MVC decoder, so it plays the 2D view
    • CDs: CD+G from a raw .sub file, and double-byte CD-TEXT
      Not builtThe second is reported, and names come from elsewhere
    • Tuners: Windows BDA tuning, DiSEqC, and a viewer and a recording sharing one tuner
      Not built
    • Game PCs: a fallback for networks that block UDP, HEVC and AV1, and adapting the bitrate
      Not builtSee Game PCs
    • A small Windows and macOS app that makes a diagnostic file without a server
      Not startedSettings → WittyDiagnoser does this with one

    Apps 9

    • WittyMediaClient, native apps: music, books, disc menus, channels and photos
      Not started on Android and AppleThe desktop app has them through the web app
    • WittyMediaClient, Apple apps
      Written, and never compiledThey need a Mac
    • WittyMediaClient, theme picker on native apps
      They use the server’s theme colours only
    • WittyMediaClient, other TVs: webOS, Tizen, Roku
      Not started
    • WittyMediaClient, Windows 7
      Not started, and needs the owner’s decision
    • A server build for Android TV, for boxes such as a Shield
      Not started
    • WittyMediaPlayer: macOS and Linux, Java menus, built-in surround sound
      Not startedIt runs on Windows
    • WittyVisualizer in the native apps
      Not started
    • WittyMediaRemoteMedia: the basics of connecting NAS libraries through a native or Docker app, in its own repository
      Not started

    Packaging 4

    • A combined Windows installer, for the server and client together
      Not startedEach has its own
    • apt and dnf repositories
      The script is ready, and none is hosted
    • Code signing on Windows and macOS
      Not bought: see Publishing a release
    • The server for Arch, Flatpak and Snap
      Not startedThe archive and install.sh work on other distributions

    Documentation 1

    • New screenshots for the README at 1920x1080
      Not retaken

  3. Waiting on hardware · 13 items

    What hasn’t met the real world

    These are written and tested as far as this machine allows, and haven’t been tried for real.

    • A clean copy of Windows 11 with Smart App Control on: the installers and every program
      Waiting for: A code-signing certificate: #65
    • A real Mac: anything at all, and iOS and tvOS
      Waiting for: A Mac
    • FreeBSD hardware or arm64: the amd64 package has run in virtual machines, and modules have only been built for it
      Waiting for: A machine
    • Real TVs, TV remotes, phones and game controllers
      Waiting for: The owner’s devices. Android has only run on emulators
    • Safari, Firefox and old TV browsers for games and the visualizer
      Waiting for: The owner’s devices
    • Screen readers with real speech
      Waiting for: A person
    • Real tuners through a helper
      Waiting for: Hardware
    • Retail Blu-rays, with Java menus, UHD HDR and MVC 3D
      Waiting for: Discs
    • A real game with a real GPU on a game PC
      Waiting for: A gaming PC: the checklist
    • Game delay on a real screen: the figures are headless, on one machine
      Waiting for: Someone playing, and a slow-motion camera
    • A real 3DS game: the only file here is encrypted, so it’s refused
      Waiting for: An unencrypted dump
    • WittyMediaPlayer’s release build on GitHub’s Windows machines
      Waiting for: A fix: WittyMediaPlayer#1
    • The complete Docker image
      Waiting for: Module tags on GitHub

Alpha software: it changes quickly and can fail or lose data. Keep backups, including your data folder, before you upgrade. No media comes with WittyMediaServer. Copy-protected discs, encrypted broadcasts and encrypted game files are refused with a plain message. Nothing here unlocks them.

This site has no cookies, trackers or analytics. Your theme choice is kept in your own browser. How this site handles privacy. Change the theme.
